## 🔥 Core DSA Topics

| Topic                          | Importance | What to Master                                               |
| ------------------------------ | ---------- | ------------------------------------------------------------ |
| **Arrays & Strings**           | ⭐⭐⭐⭐⭐      | Two pointers, sliding window, prefix sum, Kadane’s algorithm |
| **Hashing (Map/Set)**          | ⭐⭐⭐⭐⭐      | Hash map, hash set, frequency counting, subarray problems    |
| **Recursion & Backtracking**   | ⭐⭐⭐⭐       | Subsets, permutations, N-Queens, Sudoku, word search         |
| **Binary Search**              | ⭐⭐⭐⭐       | Search in sorted arrays, boundaries, rotated arrays          |
| **Sorting & Greedy**           | ⭐⭐⭐        | Merge intervals, meeting rooms, Huffman coding               |
| **Linked Lists**               | ⭐⭐⭐        | Fast/slow pointers, reverse list, detect cycles              |
| **Stacks & Queues**            | ⭐⭐⭐⭐       | Next greater element, monotonic stack, valid parentheses     |
| **Trees (BST + Binary Trees)** | ⭐⭐⭐⭐⭐      | Traversals, height, LCA, serialize/deserialize               |
| **Heaps / Priority Queues**    | ⭐⭐⭐        | Kth largest, top-k elements, merge k lists                   |
| **Graphs**                     | ⭐⭐⭐⭐⭐      | BFS, DFS, Dijkstra, Topological sort, Union-Find (DSU)       |
| **Dynamic Programming (DP)**   | ⭐⭐⭐⭐⭐      | Subset sum, knapsack, LIS, LCS, matrix paths                 |
| **Tries**                      | ⭐⭐         | Prefix search, autocomplete, word dictionary                 |
| **Bit Manipulation**           | ⭐⭐         | XOR problems, subsets, bitmask DP                            |

## 🧩 Key Algorithm Patterns 

| Pattern                     | Example Problem                                |
| --------------------------- | ---------------------------------------------- |
| **Sliding Window**          | Longest substring without repeating chars      |
| **Two Pointers**            | Container with most water, 3-sum               |
| **DFS / BFS**               | Islands count, word ladder                     |
| **Union-Find (DSU)**        | Graph connectivity, redundant connection       |
| **Binary Search on Answer** | Minimize max distance, Koko eating bananas     |
| **Topological Sort**        | Course schedule, alien dictionary              |
| **Dynamic Programming**     | Edit distance, coin change, house robber       |
| **Backtracking**            | Subsets, permutations, combinations            |
| **Greedy**                  | Merge intervals, minimum arrows, meeting rooms |
| **Heap / Priority Queue**   | K closest points, median finder                |

## 🧭 Preparation Plan (8–12 weeks)

| Week  | Focus Area                                                      | Goal                    |
| ----- | --------------------------------------------------------------- | ----------------------- |
| 1–2   | Arrays, Strings, Hashing                                        | 30 easy/medium problems |
| 3–4   | Trees, Linked Lists, Stack/Queue                                | Implement + 30 problems |
| 5–6   | Graphs, BFS/DFS, Union-Find                                     | 25 problems             |
| 7–8   | DP (Tabulation + Memoization)                                   | 20–25 problems          |
| 9–10  | Advanced patterns (Trie, Backtracking, Binary Search on Answer) | 20 problems             |
| 11–12 | Mock interviews + System design + Review weak areas             | Confidence & timing     |
