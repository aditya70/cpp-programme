Perfect — **LeetCode 309: [Best Time to Buy and Sell Stock with Cooldown](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/)** is one of the most classic examples of a **state machine dynamic programming** problem.

This one is key for understanding **DP on states / transitions**, often used in stock trading problems and general “finite-state” dynamic systems.

Let’s go step by step 👇

---

## 🧩 **Problem Summary**

You are given an array `prices`, where `prices[i]` is the price of a stock on day `i`.

You may:

* **Buy** one stock on a day.
* **Sell** your stock on another day.
* After selling, you have a **1-day cooldown** (can’t buy immediately the next day).

Return the **maximum profit** you can achieve.

---

### Example:

```
Input: prices = [1,2,3,0,2]
Output: 3
Explanation:
transactions = [buy, sell, cooldown, buy, sell]
profit = 3
```

---

## 🧠 **Intuition**

This is a **state DP** problem — we track what *state* we are in each day.

At any day `i`, you can be in **one of three states**:

| State    | Meaning                                                            |
| -------- | ------------------------------------------------------------------ |
| **hold** | You currently hold a stock                                         |
| **sold** | You just sold a stock today                                        |
| **rest** | You are not holding a stock and not in cooldown (can buy tomorrow) |

---

## ⚙️ **State Transitions**

Let’s define DP arrays:

* `hold[i]` → max profit at day `i` when you are holding a stock
* `sold[i]` → max profit at day `i` when you sold stock today
* `rest[i]` → max profit at day `i` when you are not holding stock and not in cooldown

---

### **Transition Relations**

#### 1️⃣ Buy / Hold State

You can either:

* Continue holding from yesterday (`hold[i-1]`)
* Or buy today (which you can only do if you were resting yesterday)

[
hold[i] = max(hold[i-1], rest[i-1] - prices[i])
]

---

#### 2️⃣ Sell State

You can only sell if you were holding yesterday:
[
sold[i] = hold[i-1] + prices[i]
]

---

#### 3️⃣ Rest State

You can rest if:

* You were already resting yesterday, or
* You just finished selling yesterday

[
rest[i] = max(rest[i-1], sold[i-1])
]

---

### **Initial Conditions**

| Variable  | Meaning                   | Initialization |
| --------- | ------------------------- | -------------- |
| `hold[0]` | bought stock on day 0     | `-prices[0]`   |
| `sold[0]` | can’t sell on day 0       | `0`            |
| `rest[0]` | haven’t done anything yet | `0`            |

---

## ✅ **C++ Implementation**

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n == 0) return 0;

        vector<int> hold(n, 0), sold(n, 0), rest(n, 0);

        hold[0] = -prices[0];
        sold[0] = 0;
        rest[0] = 0;

        for (int i = 1; i < n; i++) {
            hold[i] = max(hold[i-1], rest[i-1] - prices[i]);
            sold[i] = hold[i-1] + prices[i];
            rest[i] = max(rest[i-1], sold[i-1]);
        }

        return max(sold[n-1], rest[n-1]);
    }
};
```

## 🧮 **Dry Run Example**

### Input:

```
prices = [1, 2, 3, 0, 2]
```

| Day | Price | hold              | sold    | rest        | Explanation         |
| --- | ----- | ----------------- | ------- | ----------- | ------------------- |
| 0   | 1     | -1                | 0       | 0           | buy                 |
| 1   | 2     | max(-1, 0-2) = -1 | -1+2=1  | max(0,0)=0  | sell today          |
| 2   | 3     | max(-1,0-3)=-1    | -1+3=2  | max(0,1)=1  | sell again next day |
| 3   | 0     | max(-1,2-0)=2     | -1+0=-1 | max(1,2)=2  | cooldown after sell |
| 4   | 2     | max(2,2-2)=2      | 2+2=4   | max(2,-1)=2 | sell final          |

---

## ⚡ **Space Optimization**

You only ever need the previous day’s states.

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.empty()) return 0;

        int hold = -prices[0];
        int sold = 0;
        int rest = 0;

        for (int i = 1; i < prices.size(); i++) {
            int prevSold = sold;
            sold = hold + prices[i];
            hold = max(hold, rest - prices[i]);
            rest = max(rest, prevSold);
        }

        return max(sold, rest);
    }
};
```

## 🧠 **Intuition Summary**

| State    | Meaning                      | Transition                             |
| -------- | ---------------------------- | -------------------------------------- |
| **hold** | Currently holding a stock    | `max(hold[i-1], rest[i-1] - price[i])` |
| **sold** | Sold stock today             | `hold[i-1] + price[i]`                 |
| **rest** | Not holding, not in cooldown | `max(rest[i-1], sold[i-1])`            |

---

## 🧩 **Pattern Summary**

| Pattern                        | Type                   | Description                                    |
| ------------------------------ | ---------------------- | ---------------------------------------------- |
| **Stock DP (State Machine)**   | 1D State DP            | State transitions between buy/sell/rest        |
| **States = buy/sell/cooldown** | Distinct modes per day | Each day depends only on previous day’s states |
| **Category**                   | Optimization DP        | Max profit with constraints                    |

---

✅ **Category:** State DP
✅ **Core Idea:** Maintain separate states and transition between them.
✅ **Transition Graph:**
`rest → buy → sell → cooldown → rest ...`
